# Learning pipeline

1. ingest: parse catalog and overview; map formalizations.
2. search: BM25/FTS over abstracts.
3. extract: one subagent per selected family.
4. critic: reject incomplete/unsupported claims.
5. lean-verify: record formal coverage.
6. tutor: explanation + prerequisites.
7. quiz: questions/answers.
8. persist: study pack + DB notes.
